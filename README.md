# 📝 TaskFlow - To-Do List Web App

A modern and responsive To-Do List web application built using **HTML, CSS, and Vanilla JavaScript**.
TaskFlow helps users organize their daily tasks by adding, completing, filtering, and deleting tasks.

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔍 Filter tasks by All, Active, and Completed
* 🧹 Clear all completed tasks
* 📊 Real-time task statistics
* ⌨️ Press Enter to add a task
* 📱 Responsive design for mobile and desktop
* ✨ Smooth UI animations
* ⚡ Instant updates without page reload

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* DOM Manipulation
* Event Listeners
* Responsive Web Design

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.

## 🎯 Project Objective

The objective of this project is to create a dynamic front-end To-Do List application while learning DOM manipulation, event handling, dynamic UI updates, and JavaScript fundamentals.
